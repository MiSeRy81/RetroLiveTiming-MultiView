# Retro LiveTiming MultiView Edition v1.0.0

This is the first public **1.0** release of the customized Retro LiveTiming
MultiView build.

The focus is on the **MULTI 1 / MULTI 2** views:
- cleaner P1 and P4 timing tables,
- improved P2 information and speed ranking,
- chronological P3 race-control messages with the newest message at the bottom,
- theoretical best values in P4 Practice,
- and many spacing/alignment fixes.

## Qualifying status

The Qualifying layout is still under development and is not yet part of the finalized v1.0 MultiView design. Practice and Race are the optimized layouts in this release.

## Installation

1. Download `RetroLiveTiming-MultiView-v1.0.0-Windows.zip`.
2. Extract the ZIP to a folder of your choice.
3. Start `RetroLiveTiming for F1.exe`.

No manual `app.asar` replacement is required.
